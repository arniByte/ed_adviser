# Деплой на Vercel

Сайт и функции `/api` разворачиваются одним проектом.

## Шаги

1. На [openrouter.ai/keys](https://openrouter.ai/keys) создать ключ. В поле Credit limit задать потолок расходов, например 5 долларов.
2. На [vercel.com/new](https://vercel.com/new) импортировать репозиторий. Vercel сам определит Vite, настройки сборки менять не нужно.
3. В разделе Environment Variables добавить `OPENROUTER_API_KEY` со значением ключа.
4. Нажать Deploy. Через минуту сайт доступен по адресу вида `имя-проекта.vercel.app`.

Каждый пуш в `main` разворачивается автоматически.

## Переменные окружения

| Переменная           | Обязательна | Значение                                                               |
| -------------------- | ----------- | ---------------------------------------------------------------------- |
| `OPENROUTER_API_KEY` | да          | ключ OpenRouter                                                        |
| `MENTOR_MODEL`       | нет         | модель наставника, по умолчанию `anthropic/claude-haiku-5.5`           |
| `TRANSCRIBE_MODEL`   | нет         | модель распознавания речи, по умолчанию `google/gemini-3.1-flash-lite` |

После изменения переменных нужен повторный деплой: Deployments → последний → Redeploy.

## Проверка после деплоя

1. Открыть сайт и задать вопрос в «Справке» — ответ должен печататься постепенно, под ним появятся источники.
2. Пройти один кейс в тренажёре, ответить голосом — браузер попросит доступ к микрофону.
3. Если наставник отвечает ошибкой, открыть в Vercel вкладку Logs: там будет причина, чаще всего — не задан или исчерпан ключ.
