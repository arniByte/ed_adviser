Ты работаешь над проектом «Черновик» — AI-тренажёром для абитуриента и стажёра (хакатон, кейс «Цифровое наставничество и AI-менторство», Софтлайн Решения, категория Lead). Над проектом параллельно работает другой агент, поэтому сначала синхронизируйся, а в конце оставь запись о своей работе.

**1. Синхронизация — до любых правок.**

```bash
git fetch origin main agents
git worktree add ../agents origin/agents -B agents
```

Прочитай целиком `../agents/AGENTS.md` (правила, архитектура, дизайн-система, проверки) и верхние записи `../agents/HANDOFF.md` (что сделано последним и что в работе). Затем `README.md` и `docs/architecture.md` в основной ветке. Если задача пересекается с тем, что в HANDOFF отмечено как «в работе», — остановись и спроси.

**2. Задача.** [опиши задачу]

**3. Как работать.**

- Сначала план: какие файлы меняешь и почему. Потом код.
- Ветка от свежего `main`: `codex/<коротко-о-задаче>`.
- Пиши чисто и минимально: без закомментированного кода, лишних файлов, `console.log`, заглушек «на будущее». Комментарии — по-русски и только о том, почему так.
- Тексты интерфейса — на «ты», коротко, без канцелярита. Дизайн — по разделу «Дизайн-система» в AGENTS.md: стекло, аэрография, минимум текста, плавные анимации с `backwards`.
- Перед коммитом — все проверки из AGENTS.md (prettier, typecheck, тесты, check:knowledge, proofs:check, build). Интерфейс проверь глазами на 390 и 1280 пикселях.
- Коммиты — как человек: короткий заголовок на английском в повелительном наклонении. Никаких `Co-Authored-By`, упоминаний ИИ, названий моделей и ссылок на сессии — ни в коммитах, ни в PR, ни в коде.
- В `main` не добавляй служебное (инструкции деплоя, заметки, журналы) — это живёт в ветке `agents`.
- Пуш в свою ветку, PR в `main`, слияние только после зелёного CI. Историю чужих веток не переписывай.

**4. В конце сессии — запись в журнал.** Допиши сверху в `../agents/HANDOFF.md`: дата · Codex · ветка; что сделано (по пунктам, с файлами); как проверено; что осталось и на что обратить внимание. Затем:

```bash
git -C ../agents add HANDOFF.md
git -C ../agents commit -m "Log <что сделано>"
git -C ../agents push origin agents
```
