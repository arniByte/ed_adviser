# Ролик Черновика

`src/Values.tsx` — сцена 66–74 с: три принципа продукта и органичное анимированное кольцо. Финал перенесён на 74–82 с. Кольцо считается из полярных линий, без внешних изображений и генерации.

Исходные записи экрана из папки `public/clips` не хранятся в git. Чтобы повторить текущий экспорт без пересъёмки старых сцен, нужен **исходный 74-секундный** `promo.mp4` до этой правки. Например, извлеки его из предыдущего коммита продукта. Новая сцена рендерится отдельно, затем исходные сцены и музыка аккуратно склеиваются:

```bash
npm ci
node stitch-values.cjs /path/to/promo-74.mp4 /path/to/promo-82.mp4 /usr/bin/chromium
```

Результат: 1920×1080, 30 кадров/с, H.264 + AAC, 82 с. Переходы музыки сглажены короткой перекрёстной склейкой. `stitch-values.cjs` проверяет исходную длительность и запрещает перезапись исходника.

Для полного рендера композиции `Promo` сначала подготовь исходные клипы, изображения и музыку по `../../TOOLS.md`. Длина звуковой дорожки должна быть 82 с; исходный генератор музыки пока рассчитан на 74 с, поэтому для текущего экспорта используется сборщик выше.
